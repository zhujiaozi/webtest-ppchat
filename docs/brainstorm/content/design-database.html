表结构明细

1. user — 用户表

字段类型说明
idBIGINT PK AUTO主键
usernameVARCHAR(50) UQ NOT NULL登录用户名
passwordVARCHAR(255) NOT NULL密码（BCrypt 加密）
nicknameVARCHAR(50)显示昵称
avatarVARCHAR(500)头像 URL
statusINT DEFAULT 00=离线 1=在线 2=隐身
last_loginDATETIME最近登录时间
login_countINT DEFAULT 0累计登录次数
created_atDATETIME注册时间
updated_atDATETIME更新时间

2. friend_group — 好友分组表

字段类型说明
idBIGINT PK AUTO主键
user_idBIGINT FK → user所属用户
nameVARCHAR(50) NOT NULL分组名称（如"同事""同学"）
sort_orderINT DEFAULT 0排序权重

3. friend — 好友关系表

字段类型说明
idBIGINT PK AUTO主键
user_idBIGINT FK → user用户 A
friend_idBIGINT FK → user用户 B（好友）
group_idBIGINT FK → friend_group所属分组
remarkVARCHAR(50)好友备注名
created_atDATETIME成为好友时间

💡 双向存储：A 加 B 为好友时插入两条记录 (A,B) 和 (B,A)，查询更简单

4. friend_request — 好友申请表

字段类型说明
idBIGINT PK AUTO主键
from_user_idBIGINT FK → user发起者
to_user_idBIGINT FK → user接收者
messageVARCHAR(200)验证消息
statusINT DEFAULT 00=待处理 1=已同意 2=已拒绝
created_atDATETIME申请时间

5. private_message — 私聊消息表

字段类型说明
idBIGINT PK AUTO主键
sender_idBIGINT FK → user发送者
receiver_idBIGINT FK → user接收者
contentTEXT消息内容
msg_typeINT DEFAULT 00=文本 1=语音
audio_dataLONGTEXT语音 Base64（仅语音消息）
statusINT DEFAULT 00=已发送 1=已送达 2=已读
created_atDATETIME发送时间

6. group_chat — 群表

字段类型说明
idBIGINT PK AUTO主键
nameVARCHAR(100) NOT NULL群名称
owner_idBIGINT FK → user群主
avatarVARCHAR(500)群头像
noticeVARCHAR(500)群公告
created_atDATETIME创建时间

7. group_member — 群成员表

字段类型说明
idBIGINT PK AUTO主键
group_idBIGINT FK → group_chat所属群
user_idBIGINT FK → user成员
roleINT DEFAULT 00=普通成员 1=管理员 2=群主
joined_atDATETIME加入时间

8. group_message — 群聊消息表

字段类型说明
idBIGINT PK AUTO主键
group_idBIGINT FK → group_chat所属群
sender_idBIGINT FK → user发送者
contentTEXT消息内容
msg_typeINT DEFAULT 00=文本 1=语音
audio_dataLONGTEXT语音 Base64
created_atDATETIME发送时间
