# PP 在线聊天系统 — 项目部署文档

## 一、部署架构

```
用户浏览器
    │
    ▼ HTTPS (443)
┌─────────────┐
│   Nginx     │  SSL 终结 + 反向代理
│  (公网 443) │
└──────┬──────┘
       │ HTTP (127.0.0.1:10601)
       ▼
┌─────────────────────────────────┐
│  Spring Boot (内嵌 Tomcat)      │
│  pp-0.0.1-SNAPSHOT.jar          │
│  监听 127.0.0.1:10601           │
│                                 │
│  ┌───────────┐  ┌────────────┐  │
│  │ Thymeleaf │  │ WebSocket  │  │
│  │ REST API  │  │ STOMP/Sock │  │
│  └─────┬─────┘  └─────┬──────┘  │
│        │              │         │
│        ▼              ▼         │
│  ┌─────────────────────────┐   │
│  │   MySQL (远程数据库)     │   │
│  │   mysql6.sqlpub.com:3311│   │
│  └─────────────────────────┘   │
└─────────────────────────────────┘
```

**核心原则：**
- Nginx 负责 HTTPS 和对外暴露，Spring Boot 只监听 `127.0.0.1:10601`，不裸奔到公网
- SSL 证书由 Let's Encrypt 免费签发，Certbot 自动续期
- 数据库使用远程 MySQL（课程提供的云数据库）

## 三、首次部署完整流程

### 3.1 本地打包

在 Windows 开发机上执行：

```bash
cd D:\Data\Course\Web\WebProject\PP
mvnw.cmd clean package -DskipTests
```

打包成功后生成：
```
target/pp-0.0.1-SNAPSHOT.jar   (约 64MB)
```

### 3.2 服务器安装 Java 21

```bash
apt install -y openjdk-21-jre-headless
```

验证：
```bash
java -version
# openjdk version "21.0.x" ...
```

### 3.3 上传文件到服务器

```bash
# 上传 JAR 包
scp target/pp-0.0.1-SNAPSHOT.jar root@101.201.238.164:/opt/pp-chat/

# 创建上传目录（头像、语音文件存储）
ssh root@101.201.238.164 "mkdir -p /opt/pp-chat/uploads"
```

### 3.4 创建生产环境配置

在服务器上创建 `/opt/pp-chat/application-prod.yml`：

```bash
cat > /opt/pp-chat/application-prod.yml << 'EOF'
server:
  port: 10601

spring:
  thymeleaf:
    cache: true

app:
  upload-dir: /opt/pp-chat/uploads/
EOF
```

**说明：** Spring Boot 支持多环境配置。`application.yml`（打包在 JAR 内）包含所有基础配置（数据库连接、WebSocket 缓冲区等），`application-prod.yml` 只覆盖生产环境不同的几项：

| 配置项 | 开发环境（application.yml） | 生产环境（application-prod.yml） |
|--------|---------------------------|-------------------------------|
| 端口 | 8080 | 10601 |
| 模板缓存 | false（热更新） | true（性能优化） |
| 上传路径 | ./uploads/（Windows 相对路径） | /opt/pp-chat/uploads/（Linux 绝对路径） |
| 数据库 | 远程 MySQL | 同左（共享） |
| WebSocket 缓冲区 | 1MB | 同左（共享） |

启动时通过 `--spring.profiles.active=prod` 激活生产配置，两个 yml 自动合并，prod 的同名 key 会覆盖默认值。

### 3.5 配置域名 DNS

在域名注册商（或 DNS 服务商）添加 A 记录：

| 主机记录 | 记录类型 | 记录值 |
|---------|---------|--------|
| pp | A | 101.201.238.164 |

验证：
```bash
ping pp.evog.top
# 应返回 101.201.238.164
```

### 3.6 防火墙放行端口

**阿里云安全组**（控制台操作）：

| 端口 | 协议 | 来源 | 用途 |
|------|------|------|------|
| 80 | TCP | 0.0.0.0/0 | Certbot 证书验证 + HTTP |
| 443 | TCP | 0.0.0.0/0 | HTTPS 访问 |

> 注意：10601 端口**不要**对外开放，只允许本机 Nginx 访问。

**服务器防火墙：**
```bash
ufw allow 80/tcp
ufw allow 443/tcp
ufw reload
```

### 3.7 安装和配置 Nginx

```bash
apt install -y nginx
```

创建站点配置：
```bash
nano /etc/nginx/sites-available/pp.evog.top
```

写入以下内容：
```nginx
server {
    listen 80;
    server_name pp.evog.top;

    location / {
        proxy_pass http://127.0.0.1:10601;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        # WebSocket 支持（PP Chat 使用 STOMP over SockJS）
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        # 语音消息上传大小限制
        client_max_body_size 10M;
    }
}
```

**关键配置说明：**
- `proxy_set_header Upgrade/Connection`：WebSocket 握手必须，否则 STOMP 实时消息不通
- `client_max_body_size 10M`：匹配 Spring Boot 的 `max-file-size`，否则大文件上传被 Nginx 拒绝

启用配置并重启：
```bash
ln -sf /etc/nginx/sites-available/pp.evog.top /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx
```

验证 HTTP 可访问：
```bash
curl -I http://pp.evog.top
# 返回 HTTP/1.1 200 OK 或 302 跳转
```

### 3.8 申请 SSL 证书（HTTPS）

```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d pp.evog.top
```

交互过程：

| 提示 | 操作 |
|------|------|
| 输入邮箱 | 填写真实邮箱（证书到期提醒） |
| Agree to TOS | Y |
| Share email | N |
| Redirect HTTP to HTTPS | 选 `2`（Redirect） |

Certbot 会自动：
1. 申请 Let's Encrypt 免费证书
2. 修改 Nginx 配置，添加 443 SSL 块
3. 配置 HTTP → HTTPS 自动跳转
4. 设置定时任务自动续期（证书有效期 90 天，到期前自动续）

验证证书：
```bash
ls /etc/letsencrypt/live/pp.evog.top/
# fullchain.pem  privkey.pem  cert.pem  chain.pem  README
```

验证自动续期：
```bash
certbot renew --dry-run
```

### 3.9 启动应用

```bash
cd /opt/pp-chat
nohup java -jar pp-0.0.1-SNAPSHOT.jar --spring.profiles.active=prod > app.log 2>&1 &
```

等待 10-20 秒，检查启动日志：
```bash
tail -20 /opt/pp-chat/app.log
```

看到以下日志即为启动成功：
```
Tomcat started on port 10601 (http) with context path '/'
```

首次启动时 JPA 会自动建表（`ddl-auto: update`），日志中会看到建表 SQL。

## 五、环境配置说明

### 5.1 多环境配置机制

PP Chat 使用 Spring Boot 的 Profile 机制管理多环境配置：

```
application.yml          ← 基础配置（所有环境共享，打包在 JAR 内）
application-prod.yml     ← 生产环境覆盖项（放在 JAR 外，与 JAR 同目录）
```

启动时通过 `--spring.profiles.active=prod` 激活生产 Profile，两个文件自动合并，prod 的同名 key 覆盖默认值。

### 5.2 配置差异对照

| 配置项 | 开发环境 | 生产环境 | 说明 |
|--------|---------|---------|------|
| server.port | 8080 | 10601 | 生产端口不暴露到公网 |
| spring.thymeleaf.cache | false | true | 生产启用缓存提升性能 |
| app.upload-dir | ./uploads/ | /opt/pp-chat/uploads/ | Linux 绝对路径 |
| 数据库连接 | 远程 MySQL | 同左 | 共享同一数据库 |
| WebSocket 缓冲区 | 1MB | 1MB | 语音消息需要大缓冲区 |
| JPA ddl-auto | update | update | 自动建表（开发/生产一致） |

### 5.3 关键配置说明

**WebSocket 缓冲区（1MB）：**
语音消息通过 MediaRecorder 录制后转为 Base64，经由 STOMP over WebSocket 发送。Base64 编码后约 68KB，超过 STOMP 默认的 64KB 限制。通过以下三处配置同步提升到 1MB：
- `WebSocketConfig.java`：`setMessageSizeLimit(1024 * 1024)`
- `application.yml`：`spring.websocket.messaging.send-buffer-size-limit: 1048576`
- `application.yml`：`spring.messaging.stomp.buffer-size-limit: 1048576`

**数据库连接：**
使用 HikariCP 连接池，最大 10 个连接，空闲超时 10 分钟，最大生命周期 30 分钟。

## 七、常见问题排查

### 7.1 Certbot 申请证书超时

**现象：**
```
Timeout during connect (likely firewall problem)
```

**原因：** 阿里云安全组未放行 80 端口

**解决：**
1. 阿里云控制台 → ECS → 安全组 → 入方向规则 → 添加 TCP 80（来源 0.0.0.0/0）
2. 服务器执行 `ufw allow 80/tcp && ufw reload`
3. 验证：`curl -I http://pp.evog.top` 能返回响应头
4. 重新执行 `certbot --nginx -d pp.evog.top`

### 7.2 WebSocket 连接失败（聊天无法收发消息）

**现象：** 进入聊天界面后左下角显示"连接中..."，发送消息无反应

**原因：** Nginx 配置缺少 WebSocket 支持头

**检查：** 确认 Nginx 配置中有以下两行：
```nginx
proxy_set_header Upgrade $http_upgrade;
proxy_set_header Connection "upgrade";
```

**修复：** 修改配置后 `nginx -t && systemctl reload nginx`

### 7.3 语音消息发送失败

**现象：** 录音后发送，对方收不到或报错

**原因：** STOMP 缓冲区不够大，或 Nginx 的 `client_max_body_size` 太小

**检查：**
1. 确认 `application.yml` 中三处缓冲区配置都是 1MB
2. 确认 Nginx 配置中 `client_max_body_size 10M`

### 7.4 启动报端口被占用

**现象：**
```
Web server failed to start. Port 10601 was already in use.
```

**解决：**
```bash
# 查看占用端口的进程
lsof -i :10601

# 杀掉旧进程
pkill -f "pp-0.0.1-SNAPSHOT.jar"

# 等 2 秒后重新启动
sleep 2
nohup java -jar pp-0.0.1-SNAPSHOT.jar --spring.profiles.active=prod > app.log 2>&1 &
```

### 7.5 数据库连接失败

**现象：** 启动日志报 `Communications link failure`

**排查步骤：**
1. 检查 `application.yml` 中数据库地址、端口、用户名、密码
2. 服务器上测试数据库连通性：
   ```bash
   apt install -y mysql-client
   mysql -h mysql6.sqlpub.com -P 3311 -u iamgove -p
   ```
3. 如果远程数据库有 IP 白名单，需要把服务器公网 IP 加入白名单

### 7.6 上传头像/文件失败

**现象：** 上传头像或文件时报错

**检查：**
1. 上传目录是否存在且有写权限：
   ```bash
   ls -la /opt/pp-chat/uploads/
   # 确保目录存在且权限为 755
   chmod 755 /opt/pp-chat/uploads/
   ```
2. `application-prod.yml` 中 `app.upload-dir` 路径是否正确
3. Nginx 的 `client_max_body_size` 是否匹配 Spring Boot 的 `max-file-size`

### 7.7 HTTPS 证书过期

**现象：** 浏览器提示"连接不安全"

**检查自动续期：**
```bash
certbot renew --dry-run
```

**手动续期（如果自动续期失败）：**
```bash
certbot renew
systemctl reload nginx
```

### 7.8 如何查看实时日志

```bash
# 查看最近 50 行
tail -50 /opt/pp-chat/app.log

# 实时跟踪日志（Ctrl+C 退出）
tail -f /opt/pp-chat/app.log

# 搜索错误
grep -i "error\|exception" /opt/pp-chat/app.log
```

### 7.9 如何确认服务是否在运行

```bash
ps aux | grep pp-0.0.1-SNAPSHOT | grep -v grep
# 有输出表示正在运行

ss -lntp | grep 10601
# 显示 127.0.0.1:10601 表示端口正常监听
```

## 八、安全措施

| 措施 | 说明 |
|------|------|
| 10601 仅监听本地 | `server.address: 127.0.0.1`，公网无法直接访问 |
| Nginx 反向代理 | 外部只能通过 443 HTTPS 访问 |
| SSL/TLS 证书 | Let's Encrypt 免费证书，自动续期 |
| HTTP → HTTPS 跳转 | Certbot 自动配置，所有 HTTP 请求重定向到 HTTPS |
| 密码 BCrypt 加密 | 数据库中不存储明文密码 |
| @JsonIgnore | API 响应中隐藏密码字段 |
| Session 认证 | WebSocket 握手时验证 Session |
| SQL 注入防护 | JPA 参数化查询 |
| XSS 防护 | 前端 escapeHtml 转义用户输入 |

## 九、性能调优（可选）

### 9.1 JVM 参数优化

默认启动不指定 JVM 参数，生产环境可根据服务器内存调整：

```bash
nohup java -Xms256m -Xmx512m -XX:+UseG1GC \
  -jar pp-0.0.1-SNAPSHOT.jar \
  --spring.profiles.active=prod > app.log 2>&1 &
```

| 参数 | 说明 |
|------|------|
| -Xms256m | 初始堆内存 256MB |
| -Xmx512m | 最大堆内存 512MB |
| -XX:+UseG1GC | 使用 G1 垃圾回收器 |

### 9.2 Nginx 缓存优化

在 Nginx 配置中添加静态资源缓存：

```nginx
location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff2)$ {
    proxy_pass http://127.0.0.1:10601;
    expires 7d;
    add_header Cache-Control "public, immutable";
}
```
