# PP 在线聊天系统 — 项目部署文档

## 一、环境要求

### 1.1 服务器环境
- **操作系统**：Linux (Ubuntu 20.04 / CentOS 7+)
- **Java 版本**：JDK 21
- **数据库**：MySQL 8.0+
- **Web 服务器**：Spring Boot 内嵌 Tomcat
- **反向代理**：Nginx（可选，用于 HTTPS 和静态资源）

### 1.2 开发环境
- **IDE**：IntelliJ IDEA 2023+ / Eclipse
- **构建工具**：Maven 3.8+
- **Java 版本**：JDK 21
- **数据库**：MySQL 8.0+（本地或远程）

## 二、本地开发部署

### 2.1 克隆项目
```bash
git clone https://github.com/zhujiaozi/webtest-ppchat.git
cd webtest-ppchat
```

### 2.2 配置数据库
修改 `src/main/resources/application.yml`：
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/pp_db?useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
    username: root
    password: your_password
```

### 2.3 创建数据库
```sql
CREATE DATABASE pp_db DEFAULT CHARACTER SET utf8mb4;
```

### 2.4 启动项目
```bash
./mvnw spring-boot:run
```

### 2.5 访问应用
浏览器打开：http://localhost:8080

## 三、生产环境部署

### 3.1 打包项目
```bash
./mvnw clean package -DskipTests
```
生成的 jar 包位于：`target/pp-0.0.1-SNAPSHOT.jar`

### 3.2 上传到服务器
```bash
scp target/pp-0.0.1-SNAPSHOT.jar user@server:/opt/pp-chat/
```

### 3.3 配置生产环境 application.yml
在服务器上创建 `/opt/pp-chat/application.yml`：
```yaml
server:
  port: 8443
  ssl:
    enabled: true
    key-store: file:/opt/pp-chat/keystore.p12
    key-store-password: your_keystore_password
    key-store-type: PKCS12
    key-alias: ppchat

spring:
  datasource:
    url: jdbc:mysql://mysql6.sqlpub.com:3311/gove_sqlpub?useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
    username: iamgove
    password: AtnWe0aw7DAwB0gX
  jpa:
    hibernate:
      ddl-auto: update
  thymeleaf:
    cache: true
  websocket:
    messaging:
      send-buffer-size-limit: 1048576
      message-size-limit: 1048576
  messaging:
    stomp:
      buffer-size-limit: 1048576

app:
  upload-dir: /var/lib/pp-chat/uploads/
```

### 3.4 创建上传目录
```bash
mkdir -p /var/lib/pp-chat/uploads/
chmod 755 /var/lib/pp-chat/uploads/
```

### 3.5 SSL 证书配置（可选）
生成自签名证书或使用 Let's Encrypt：
```bash
# 生成 keystore
keytool -genkeypair -alias ppchat -keyalg RSA -keysize 2048 \
  -storetype PKCS12 -keystore /opt/pp-chat/keystore.p12 \
  -validity 365 -storepass your_keystore_password
```

### 3.6 启动服务
```bash
cd /opt/pp-chat
nohup java -jar pp-0.0.1-SNAPSHOT.jar --spring.config.location=./application.yml > app.log 2>&1 &
```

### 3.7 验证部署
```bash
# 检查进程
ps aux | grep pp-0.0.1-SNAPSHOT

# 检查日志
tail -f app.log

# 测试访问
curl -k https://your_domain:8443
```

## 四、Nginx 反向代理配置（可选）

### 4.1 安装 Nginx
```bash
sudo apt install nginx
```

### 4.2 配置反向代理
编辑 `/etc/nginx/sites-available/pp-chat`：
```nginx
server {
    listen 443 ssl http2;
    server_name your_domain.com;

    ssl_certificate /etc/letsencrypt/live/your_domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your_domain.com/privkey.pem;

    location / {
        proxy_pass https://localhost:8443;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # WebSocket 支持
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }

    location /uploads/ {
        alias /var/lib/pp-chat/uploads/;
        expires 30d;
    }
}

server {
    listen 80;
    server_name your_domain.com;
    return 301 https://$server_name$request_uri;
}
```

### 4.3 启用配置
```bash
sudo ln -s /etc/nginx/sites-available/pp-chat /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
```

## 五、系统服务配置（systemd）

### 5.1 创建服务文件
编辑 `/etc/systemd/system/pp-chat.service`：
```ini
[Unit]
Description=PP Chat Application
After=network.target mysql.service

[Service]
Type=simple
User=www-data
Group=www-data
WorkingDirectory=/opt/pp-chat
ExecStart=/usr/bin/java -jar /opt/pp-chat/pp-0.0.1-SNAPSHOT.jar --spring.config.location=/opt/pp-chat/application.yml
Restart=on-failure
RestartSec=10
StandardOutput=append:/var/log/pp-chat/app.log
StandardError=append:/var/log/pp-chat/error.log

[Install]
WantedBy=multi-user.target
```

### 5.2 启用服务
```bash
sudo systemctl daemon-reload
sudo systemctl enable pp-chat
sudo systemctl start pp-chat
sudo systemctl status pp-chat
```

## 七、常见问题排查

### 7.1 端口被占用
```bash
# 查看端口占用
lsof -i :8080
# 杀死进程
kill -9 <PID>
```

### 7.2 数据库连接失败
- 检查 MySQL 是否启动
- 检查防火墙是否允许 3306 端口
- 检查数据库用户名密码是否正确

### 7.3 WebSocket 连接失败
- 检查 STOMP 缓冲区配置是否正确
- 检查 Session 是否有效
- 检查防火墙是否允许 WebSocket 连接

### 7.4 文件上传失败
- 检查上传目录是否存在且有写权限
- 检查文件大小是否超过限制（10MB）
- 检查 `app.upload-dir` 配置是否正确

## 八、性能调优建议

### 8.1 JVM 参数优化
```bash
java -Xms512m -Xmx1024m -XX:+UseG1GC -jar pp-0.0.1-SNAPSHOT.jar
```

### 8.2 数据库连接池优化
```yaml
spring:
  datasource:
    hikari:
      maximum-pool-size: 20
      minimum-idle: 5
      connection-timeout: 30000
```

### 8.3 静态资源缓存
```yaml
spring:
  web:
    resources:
      cache:
        period: 3600
```
