PP Chat

Spring Boot + WebSocket 实时聊天系统

技术栈

Spring Boot 4.0.6

Java 21 后端框架，REST API + WebSocket

WebSocket STOMP

实时双向通信，1MB 缓冲区支持语音传输

MySQL 8.0 + JPA

10 张核心表，好友双向存储设计

原生 JS SPA

Thymeleaf 模板引擎，8 个模块化 JS 文件

Session 认证

自定义拦截器，BCrypt 密码加密

Nginx + HTTPS

Lets Encrypt 证书，端口仅监听 127.0.0.1

私聊消息流转（群聊同理）

1

前端发送

用户输入消息，点击发送。stompClient.send('/app/chat/private', {}, JSON.stringify(message))

2

后端接收

ChatController 的 @MessageMapping("/chat/private") 接收消息

3

身份校验

验证 Principal（WebSocket 握手时设置），确保发送者身份合法

4

保存数据库

ChatService 将消息保存到 pp_private_message 表

5

实时推送

messagingTemplate.convertAndSendToUser(receiverId, "/queue/private", message)

6

客户端接收

接收者订阅 /user/queue/private，收到消息后实时渲染到聊天窗口

语音消息实现（技术亮点）

1

申请麦克风权限

navigator.mediaDevices.getUserMedia({audio: true}) 获取音频流（需 HTTPS）

2

MediaRecorder 录音

创建 MediaRecorder，格式 audio/webm;codecs=opus，限制 10 秒防止文件过大

3

转 Base64

录音结束后，通过 FileReader 将 Blob 转为 Base64 Data URL（约 68KB）

4

WebSocket 发送

通过 STOMP 发送，需要 1MB 缓冲区支持（默认 64KB 不够）

5

后端解码

FileService.saveBase64Audio() 解码 Base64，保存到 /uploads/audio/xxx.webm

6

数据库存 URL

只存文件路径，避免数据库膨胀

7

播放

接收者获取 URL，new Audio(url).play() 实时播放

好友管理

搜索用户、好友申请、分组管理、备注、移动、双向存储

私聊

实时文本消息、未读计数、聊天记录搜索、导出 TXT

群聊

创建群聊、群公告、邀请/申请机制、成员管理、实时广播

语音消息

浏览器录音、Base64 传输、文件落盘、实时播放

后台管理

独立管理员认证、仪表盘统计、数据维护、级联删除

数据库设计（10 张核心表）

pp_user

用户表，BCrypt 密码，登录统计

好友分组，支持自定义分组

pp_friend

pp_friend_request

好友申请，状态流转

pp_private_message

pp_group_chat

群聊信息，群主、公告

pp_group_member

pp_group_message

群聊消息，广播机制

pp_group_invitation

群邀请/申请，type 区分

pp_admin

管理员，独立认证

部署架构

服务器环境

Ubuntu 24.04 + OpenJDK 21

反向代理

应用配置

端口 127.0.0.1:10601，仅 Nginx 可访问

数据库
