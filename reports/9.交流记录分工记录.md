## 二、Git 可验证的协作方式

从当前仓库的 Git 历史可以确认，本项目采用了“主分支持续推进 + 功能分支合并 + 文档同步更新”的协作方式，主要表现为：

1. **主线开发持续推进**
   - 主分支上连续完成了项目初始化、依赖配置、实体类、Repository、用户认证、好友/私聊/群聊/个人中心、UI 重构、后台管理、通知中心、文档整理等工作。

2. **通过分支合并集成多人改动**
   - `Merge pull request #1 from zhujiaozi/copilot/implement-chat-management-and-friend-management`
   - `Merge pull request #3 from zhujiaozi/unify-api-ignore-uploads`
   - `Merge pull request #4 from zhujiaozi/fix/security-and-quality`
   - `Merge pull request #5 from zhujiaozi/strickensun/admin-login-lockout`
   - `Merge branch 'refactor/ui-overhaul'`
