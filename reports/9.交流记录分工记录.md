## 二、分工说明（每人负责一个模块的全流程）

### 模块1：账户系统 — 陈弦

**负责内容：**
- 数据库表设计：`pp_user` 表结构设计
- 后端实体：`User.java` 实体类编写
- 后端 Repository：`UserRepository.java` 数据访问接口
- 后端 Service：`UserService.java` 注册、登录、密码管理、级联删除等业务逻辑
- 后端 Controller：`PageController.java` 登录/注册/忘记密码页面路由
- 后端 Controller：`ProfileRestController.java` 个人资料、昵称、头像、密码修改 API
- 前端页面：`login.html`、`register.html`、`forgot-password.html` 模板编写
- 前端 JS：`chat-profile.js` 个人中心界面渲染、表单交互
- 安全配置：`LoginInterceptor.java` 登录拦截器、BCrypt 密码加密配置
- 单元测试：`UserServiceTest.java` 测试用例编写

**技术要点：**
- BCryptPasswordEncoder 密码加密
- HttpSession Session 管理
- Thymeleaf 表单渲染
- JPA `findByUsername` 查询
- MultipartFile 文件上传（头像）
- @JsonIgnore 隐藏敏感字段

### 模块3：群聊管理 — 沈越

**负责内容：**

- 后端实体：`GroupChat.java`、`GroupMember.java`、`GroupMessage.java`、`GroupInvitation.java`
- 后端 Repository：`GroupChatRepository.java`、`GroupMemberRepository.java`、`GroupMessageRepository.java`、`GroupInvitationRepository.java`

### 模块4：消息系统 — 宋佳伟

**负责内容：**
- 数据库表设计：`pp_private_message` 表结构
- 后端实体：`PrivateMessage.java`
- 后端 Repository：`PrivateMessageRepository.java` 对话查询、搜索、已读标记、未读计数等查询方法
- 后端 Service：`ChatService.java` 消息保存、对话获取、搜索、导出等业务逻辑
- 后端 Controller：`ChatRestController.java` 全部 REST API 端点
- WebSocket Controller：`ChatController.java` STOMP 私聊/群聊消息处理
- WebSocket 配置：`WebSocketConfig.java` STOMP 端点、认证握手、缓冲区配置
- 前端 JS：`chat-view.js` 聊天界面渲染、消息收发、历史记录加载、搜索功能
- 前端 JS：`chat-core.js` 全局状态、WebSocket 连接/重连、消息发送、视图切换
- 单元测试：`ChatServiceTest.java` 测试用例编写

**技术要点：**
- WebSocket STOMP 点对点消息推送 (`convertAndSendToUser`)
- WebSocket STOMP 广播消息 (`convertAndSend` to `/topic/group/{id}`)
- DefaultHandshakeHandler 设置 Principal 实现用户路由
- 消息状态机（已发送→已送达→已读）
- 批量未读计数查询 (`GROUP BY senderId`)
- Generation counter 防止异步视图加载竞态条件
- 乐观更新（发送中状态指示器）
- 聊天记录 TXT 导出格式化

### 模块5：语音消息 — 郭峰（组长）

**负责内容：**
- 前端录音：`chat-view.js` MediaRecorder API 集成、音频 Blob 转 Base64
- 后端处理：`ChatController.java` 语音消息接收、Base64 解码、文件存储
- 文件服务：`FileService.java` 音频文件保存、URL 生成
- WebSocket 配置：STOMP 缓冲区大小调优（1MB）解决语音传输问题
- 应用配置：`application.yml` WebSocket/STOMP 缓冲区参数配置
- 项目统筹：整体架构设计、代码审查、分支合并、部署配置
- Landing 页面：`landing.html` 首页设计与实现

**技术要点：**
- MediaRecorder API (`audio/webm;codecs=opus`)
- FileReader.readAsDataURL() Base64 编码
- STOMP 消息大小限制配置 (1MB)
- Base64 → 文件存储（避免数据库存储大文本）
- 文件名 sanitization（去除空格等特殊字符）
