PP Chat

Spring Boot + WebSocket 实时聊天系统

技术栈

Spring Boot 4.0.6

Java 21 后端框架，REST API + WebSocket

WebSocket STOMP

实时双向通信，1MB 缓冲区支持语音传输

MySQL 8.0 + JPA

10 张核心表，好友双向存储设计

原生 JS SPA

2964 行代码，8 个模块化文件

Session 认证

自定义拦截器，BCrypt 密码加密

Nginx + HTTPS

Lets Encrypt 证书，端口仅监听 127.0.0.1

私聊消息流转

1

前端发送

stompClient.send('/app/chat/private')

2

后端处理

ChatController 校验保存到 pp_private_message 表

3

实时推送

convertAndSendToUser(receiverId, "/queue/private")

4

客户端接收

订阅 /user/queue/private 实时渲染

语音消息（技术亮点）

1

MediaRecorder 录音

audio/webm;codecs=opus，限制 10 秒

2

Base64 传输

Data URL 通过 WebSocket 发送（约 68KB）

3

文件落盘

FileService 解码保存到 /uploads/audio/

4

数据库存 URL

只存路径，前端 new Audio(url).play() 播放

关键：三处缓冲区同步扩大到 1MB
