# PP 在线聊天系统 — 测试用例文档

## 一、测试概述

### 1.1 测试范围
- 单元测试：Service 层业务逻辑
- 集成测试：Controller 层 API 接口
- 功能测试：端到端用户操作流程

### 1.2 测试环境
- **测试框架**：JUnit 5 + Mockito + Spring Boot Test
- **数据库**：H2 内存数据库（单元测试）/ MySQL（集成测试）
- **构建工具**：Maven Surefire Plugin

### 1.3 运行测试
```bash
# 运行所有测试
./mvnw test

# 运行指定测试类
./mvnw test -Dtest=FriendServiceTest

# 跳过测试
./mvnw package -DskipTests
```

## 五、性能测试

### 5.1 并发测试
- **目标**：50 个用户同时在线聊天
- **工具**：JMeter / Apache Bench
- **指标**：
  - 平均响应时间 < 500ms
  - 95% 请求响应时间 < 1s
  - 错误率 < 1%

### 5.2 WebSocket 压力测试
- **目标**：100 个并发 WebSocket 连接
- **指标**：
  - 连接建立成功率 100%
  - 消息延迟 < 200ms
  - 无消息丢失

## 六、安全测试

### 6.1 SQL 注入测试
- 在搜索框输入 `' OR '1'='1` 等特殊字符
- 预期：查询正常执行，无异常

### 6.2 XSS 测试
- 在消息中输入 `<script>alert('xss')</script>`
- 预期：脚本被转义，不执行

### 6.3 未授权访问测试
- 未登录状态下访问 `/api/friends`
- 预期：返回 401 或重定向至登录页

### 6.4 权限测试
- 普通成员尝试踢出其他成员
- 预期：返回 403 或"只有群主可以踢出成员"
