# PP 在线聊天系统 — 接口设计文档

## 一、接口规范

### 1.1 统一响应格式

所有 REST API 返回统一的 JSON 格式：

**成功响应：**
```json
{
  "code": 200,
  "message": "success",
  "data": { ... }
}
```

**错误响应：**
```json
{
  "code": 400,
  "message": "错误描述",
  "data": null
}
```

**HTTP 状态码：**
| 状态码 | 含义 |
|--------|------|
| 200 | 请求成功 |
| 400 | 请求参数错误 |
| 401 | 未认证（未登录） |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

### 1.2 认证方式

- **Session 认证**：登录后将 User 对象存入 HttpSession
- **拦截器**：LoginInterceptor 拦截所有请求，检查 Session 中的 currentUser
- **排除路径**：`/`, `/login`, `/register`, `/forgot-password`, `/css/**`, `/js/**`, `/uploads/**`

### 1.3 WebSocket 认证

- **握手拦截**：AuthHandshakeInterceptor 检查 Session 中的 currentUser
- **Principal 设置**：握手成功后设置 Principal 为用户ID，用于 `convertAndSendToUser` 路由

| 路径 | 方法 | 功能 | 模板 |

## 三、REST API 详细设计

### 3.1 好友管理 API (`/api/friends`)

#### 3.1.1 获取好友列表和分组
```
GET /api/friends
Response: {
  "groups": [{ "id": 1, "name": "我的好友", ... }],
  "friends": [{ "id": 1, "userId": 1, "friendId": 2, "remark": "张三", "friendName": "张三", "groupId": 1, ... }]
}
```

#### 3.1.2 搜索用户（用于加好友）
```
GET /api/friends/search?keyword=张
Response: [{ "id": 2, "username": "zhangsan", "nickname": "张三", ... }]
```

#### 3.1.3 搜索好友（用于发起私聊）
```
GET /api/friends/search-friends?keyword=张
Response: [{ "id": 2, "username": "zhangsan", "nickname": "张三", ... }]
```

#### 3.1.4 发送好友申请
```
POST /api/friends/request
Body: { "toUserId": 2, "message": "你好" }
Response: { "success": true } 或 { "success": false, "error": "已经是好友了" }
```

#### 3.1.5 获取好友申请列表
```
GET /api/friends/requests
Response: [{
  "id": 1,
  "fromUserId": 2,
  "fromUserName": "张三",
  "toUserId": 1,
  "message": "你好",
  "status": 0,
  "createdAt": "2026-05-21T10:00:00"
}]
```

#### 3.1.6 同意好友申请
```
POST /api/friends/requests/{id}/accept
Response: { "code": 200, "message": "success" }
```

#### 3.1.7 拒绝好友申请
```
POST /api/friends/requests/{id}/reject
Response: { "code": 200, "message": "success" }
```

#### 3.1.8 创建好友分组
```
POST /api/friends/groups
Body: { "name": "同事" }
Response: { "id": 2, "name": "同事", "userId": 1, ... }
```

#### 3.1.9 重命名分组
```
PUT /api/friends/groups/{id}
Body: { "name": "新名称" }
Response: { "code": 200, "message": "success" }
```

#### 3.1.10 删除分组
```
DELETE /api/friends/groups/{id}
Response: { "code": 200, "message": "success" }
说明：删除前自动将该组内好友移至未分组
```

#### 3.1.11 删除好友
```
DELETE /api/friends/{friendId}
Response: { "code": 200, "message": "success" }
说明：双向删除好友关系
```

#### 3.1.12 移动好友到指定分组
```
PUT /api/friends/{friendId}/move
Body: { "groupId": 2 }
Response: { "code": 200, "message": "success" }
```

#### 3.1.13 设置好友备注
```
PUT /api/friends/{friendId}/remark
Body: { "remark": "新备注" }
Response: { "code": 200, "message": "success" }
```

### 3.2 私聊 API (`/api/chat`)

#### 3.2.1 获取对话历史
```
GET /api/chat/private/{friendId}
Response: [{
  "id": 1,
  "senderId": 1,
  "receiverId": 2,
  "content": "你好",
  "msgType": 0,
  "audioData": null,
  "status": 2,
  "createdAt": "2026-05-21T10:00:00"
}]
```

#### 3.2.2 搜索对话内容
```
GET /api/chat/private/{friendId}/search?keyword=你好
Response: [{ ... }] // 匹配的消息列表
```

#### 3.2.3 标记消息为已读
```
POST /api/chat/private/{friendId}/read
Response: { "code": 200, "message": "success" }
说明：将该好友发来的所有未读消息标记为已读
```

#### 3.2.4 获取未读消息数
```
GET /api/chat/private/{friendId}/unread
Response: 3  // 未读消息数量
```

#### 3.2.5 批量获取未读消息数
```
GET /api/chat/private/unread-all
Response: { "2": 3, "3": 1, "5": 0 }  // { friendId: unreadCount }
说明：一次性获取所有好友的未读数，避免N+1查询
```

#### 3.2.6 导出对话记录
```
GET /api/chat/private/{friendId}/export
Response: 下载 chat.txt 文件
格式：[2026-05-21T10:00:00] 张三: 你好
```

#### 3.3.8 邀请成员入群

#### 3.3.11 拒绝群聊邀请

#### 3.3.12 获取群消息列表

PUT /api/profile/password

## 四、WebSocket STOMP 协议

### 4.1 连接端点

```
WebSocket URL: ws://localhost:8080/ws (SockJS降级支持)
STOMP 连接后订阅：
  - /user/{userId}/queue/private  （私聊消息）
  - /topic/group/{groupId}        （群聊消息）
```

### 4.2 发送私聊消息

```
Destination: /app/chat/private
Body: {
  "senderId": 1,
  "sender": "张三",
  "receiverId": 2,
  "receiver": "2",
  "content": "你好",
  "msgType": 0,
  "audioData": null,
  "isGroup": false
}
```

### 4.3 发送群聊消息

```
Destination: /app/chat/group
Body: {
  "senderId": 1,
  "sender": "张三",
  "receiverId": null,
  "receiver": "1",
  "content": "大家好",
  "msgType": 0,
  "audioData": null,
  "isGroup": true
}
```

### 4.4 接收私聊消息

```
Subscription: /user/{userId}/queue/private
Message: {
  "id": 1,
  "senderId": 2,
  "sender": "李四",
  "receiverId": 1,
  "content": "你好",
  "msgType": 0,
  "audioData": null,
  "time": "2026-05-21T10:00:00",
  "status": 0
}
```

### 4.5 接收群聊消息

```
Subscription: /topic/group/{groupId}
Message: {
  "id": 1,
  "senderId": 2,
  "sender": "李四",
  "content": "大家好",
  "msgType": 0,
  "audioData": null,
  "time": "2026-05-21T10:00:00"
}
```

### 4.6 语音消息格式

```
msgType: 1
audioData: "data:audio/webm;base64,GkXfo..."  (Base64编码的WebM音频)
content: "[语音消息 5s]"  (显示文本)
```

## 五、错误码定义

| 错误码 | 含义 | 场景 |
|--------|------|------|
| 200 | 成功 | 请求正常完成 |
| 400 | 参数错误 | 请求参数缺失或格式错误 |
| 401 | 未认证 | 未登录或Session过期 |
| 403 | 无权限 | 无权操作该资源 |
| 404 | 资源不存在 | 请求的资源不存在 |
| 500 | 服务器错误 | 服务器内部异常 |

## 六、性能优化

### 6.1 批量查询
- `/api/chat/private/unread-all` — 一次性获取所有好友未读数
- `/api/friends/requests` — 返回 enriched 数据，包含发送者名称
- `/api/groups/{id}/messages` — 批量加载发送者信息

### 6.2 缓存策略
- Thymeleaf 模板缓存（生产环境启用）
- HikariCP 连接池（最大10个连接）

### 6.3 WebSocket 优化
- 消息大小限制：1MB（支持语音消息）
- 发送缓冲区：1MB
- 发送超时：20秒
