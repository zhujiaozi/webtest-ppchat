# 项目代码地址

- **GitHub 仓库**：https://github.com/zhujiaozi/webtest-ppchat
- **默认分支**：main
- **构建工具**：Maven Wrapper（`mvnw` / `mvnw.cmd`）

## 快速开始

```bash
# 克隆项目
git clone https://github.com/zhujiaozi/webtest-ppchat.git
cd webtest-ppchat

# 编译
mvnw.cmd compile

# 运行测试
mvnw.cmd test

# 启动应用
mvnw.cmd spring-boot:run

# 打包部署
mvnw.cmd clean package -DskipTests
```

## 项目结构

```
PP/
├── src/main/java/com/ncu/pp/     # 后端 Java 代码
│   ├── config/                    # 配置类（Web、WebSocket）
│   ├── entity/                    # JPA 实体（10 个表）
│   ├── repository/                # 数据访问层
│   ├── service/                   # 业务逻辑层
│   ├── controller/                # 控制器（页面、REST、WebSocket）
│   ├── interceptor/               # 拦截器（登录、管理员）
│   └── dto/                       # 数据传输对象
├── src/main/resources/
│   ├── templates/                 # Thymeleaf 页面模板
│   ├── static/css/                # 全局样式
│   ├── static/js/                 # 前端 JavaScript 模块
│   ├── application.yml            # 应用配置
│   └── application-prod.yml       # 生产环境配置
├── src/test/                      # 单元测试
├── reports/                       # 课程报告文档
└── pom.xml                        # Maven 配置
```
