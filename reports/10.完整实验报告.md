## 一、项目概述

### 1.1 项目背景

PP 在线聊天系统是一个基于 Web 的即时通讯应用，采用 Spring Boot 4.0.6 + Java 21 技术栈开发。系统支持用户注册登录、好友管理（分组）、一对一私聊、多人群聊、语音消息、聊天记录查询与导出等核心功能。

### 1.2 评分目标对照

| 课程要求 | 对应功能模块 | 实现状态 |
|----------|-------------|---------|
| 登录与注册 | 用户认证模块 | ✅ 已实现 |
| 聊天管理（私聊、群聊） | 私聊模块 + 群聊模块 | ✅ 已实现 |
| 查询聊天记录，下载到本地 | 聊天记录搜索 + TXT 导出 | ✅ 已实现 |
| 语音聊天（+5分） | 语音消息模块 | ✅ 已实现 |
| 好友管理（分组、移动、删除、重新发送验证信息） | 好友管理模块 | ✅ 已实现 |

### 1.3 技术栈

| 层次 | 技术选型 | 版本 |
|------|---------|------|
| Web框架 | Spring Boot | 4.0.6 |
| 编程语言 | Java | 21 |
| 持久层 | Spring Data JPA + Hibernate | - |

| 模板引擎 | Thymeleaf | - |

## 二、需求分析

### 2.1 功能性需求

#### 2.1.1 用户认证
- 用户注册（用户名 + 密码 + 昵称）
- 用户登录（Session 鉴权，密码 BCrypt 加密）
- 用户登出（销毁 Session）
- 忘记密码（通过用户名重置密码）
- 记录登录次数和最近登录时间

#### 2.1.2 好友管理
- 搜索用户（按用户名/昵称模糊搜索）
- 发送好友申请（附验证消息）
- 同意/拒绝好友申请
- 好友分组管理（创建/重命名/删除）
- 移动好友到指定分组
- 设置好友备注名
- 删除好友（双向删除）

#### 2.1.3 私聊
- 从好友列表发起私聊
- 实时文本消息收发（WebSocket STOMP）
- 语音消息录制与发送（MediaRecorder API）
- 消息状态追踪（已发送 → 已送达 → 已读）
- 未读消息计数与红点提示
- 聊天记录关键词搜索
- 聊天记录导出为 TXT 文件

#### 2.1.4 群聊
- 创建群聊（选好友入群）
- 群消息实时收发（WebSocket 广播）
- 群成员管理（邀请/踢出/退出）
- 群公告编辑（仅群主）
- 解散群聊（仅群主）
- 群聊邀请（发送/接受/拒绝）
- 群聊天记录导出

#### 2.1.5 个人中心
- 查看个人资料（头像、昵称、登录统计）
- 修改昵称
- 修改密码（需验证旧密码）
- 主题切换（亮色/暗色/跟随系统）

### 2.2 非功能性需求

- **性能**：页面加载 < 2秒，WebSocket 延迟 < 500ms
- **安全**：BCrypt 密码加密，Session 认证，防 XSS/SQL 注入
- **可用性**：微信/QQ 风格界面，响应式设计，操作反馈及时
- **兼容性**：支持 Chrome/Firefox/Edge 等现代浏览器

## 六、关键技术

### 6.1 WebSocket STOMP 实时通信

**配置要点：**
```java
@Configuration
@EnableWebSocketMessageBroker
public class WebSocketConfig implements WebSocketMessageBrokerConfigurer {
    @Override
    public void configureMessageBroker(MessageBrokerRegistry config) {
        config.enableSimpleBroker("/topic", "/queue");
        config.setApplicationDestinationPrefixes("/app");
    }

    @Override
    public void registerStompEndpoints(StompEndpointRegistry registry) {
        registry.addEndpoint("/ws")
                .setAllowedOriginPatterns("*")
                .addInterceptors(new AuthHandshakeInterceptor())
                .withSockJS()
                .setSuppressCors(true);
    }
}
```

**认证握手：**
```java
static class AuthHandshakeInterceptor implements HandshakeInterceptor {
    @Override
    public boolean beforeHandshake(..., Map<String, Object> attributes) {
        HttpSession session = servletRequest.getServletRequest().getSession(false);
        if (session != null && session.getAttribute("currentUser") != null) {
            attributes.put("currentUser", session.getAttribute("currentUser"));
            return true;
        }
        return false;
    }
}
```

## 九、问题与解决

### 9.1 STOMP 缓冲区限制导致语音发送失败

**问题：** 语音 Base64 数据 (~68KB) 超过 STOMP 默认 64KB 缓冲区限制

**解决：**
```java
@Override
public void configureWebSocketTransport(WebSocketTransportRegistration registration) {
    registration.setMessageSizeLimit(1024 * 1024);   // 1MB
    registration.setSendBufferSizeLimit(1024 * 1024);
}
```

同时在 `application.yml` 中配置：
```yaml
spring:
  websocket:
    messaging:
      send-buffer-size-limit: 1048576
      message-size-limit: 1048576
  messaging:
    stomp:
      buffer-size-limit: 1048576
```

### 9.2 WebSocket 消息无法推送到接收方

**问题：** `convertAndSendToUser` 需要 Principal 来路由消息，但握手时未设置

**解决：** 在 `DefaultHandshakeHandler` 中设置 Principal
```java
.setHandshakeHandler(new DefaultHandshakeHandler() {
    @Override
    protected Principal determineUser(..., Map<String, Object> attributes) {
        Object user = attributes.get("currentUser");
        if (user instanceof User u) {
            final String userId = u.getId().toString();
            return () -> userId;
        }
        return null;
    }
})
```

### 9.3 快速切换视图导致内容混合

**问题：** 异步加载时，前一个请求未完成就发起新请求，导致内容混合

**解决：** Generation counter 模式
```javascript
let viewGeneration = 0;
function switchView(view) {
    const gen = ++viewGeneration;
    loadChatView(gen);
}
async function loadChatView(gen) {
    const isStale = () => gen !== viewGeneration;
    await fetch(...);
    if (isStale()) return;
}
```

### 9.4 N+1 查询性能问题

**问题：** 循环中逐个查询数据库

**解决：** 批量查询 + Map 缓存
```java
List<Long> ids = messages.stream().map(m -> m.getSenderId()).distinct().toList();
Map<Long, User> userMap = userRepository.findAllById(ids).stream()
    .collect(Collectors.toMap(User::getId, u -> u));
```

### 9.5 删除分组后好友 groupId 残留

**问题：** 删除分组后，好友记录中的 groupId 仍指向已删除的分组

**解决：** 删除前先将好友移至未分组
```java
@Transactional
public void deleteGroup(Long groupId) {
    List<Friend> friendsInGroup = friendRepository.findByGroupId(groupId);
    for (Friend friend : friendsInGroup) {
        friend.setGroupId(null);
        friendRepository.save(friend);
    }
    friendGroupRepository.deleteById(groupId);
}
```

### 9.6 文件名含空格导致 URL 访问失败

**问题：** 上传的文件名包含空格，浏览器无法正确访问

**解决：** 文件名 sanitization
```java
String safeFilename = originalFilename.replaceAll("[^a-zA-Z0-9_.\\-]", "_");
```

### 9.7 密码字段在 API 响应中泄露

**问题：** User 对象存储在 Session 中，API 返回时包含 password 字段

**解决：** 添加 `@JsonIgnore` 注解
```java
@JsonIgnore
@Column(nullable = false)
private String password;
```
